# 旅の動画自動整理アプリ

Google Drive上の「撮影素材」フォルダ内の動画を、Gemini AIで自動リネームし、縦横・日付ごとにフォルダ分けするCLIツールです。

## 処理の流れ

1. **AIリネーム** — 動画の先頭フレームをGemini AIに送り、撮影場所と内容を判定。ファイル名を `場所_内容_連番_MM-DD-YYYY.拡張子` に変更
2. **縦横フォルダ振り分け** — 解像度から縦長/横長を判定し、「縦動画」「横動画」フォルダへ移動
3. **日付フォルダ振り分け** — 撮影日時に基づき `〇月/日付範囲/` サブフォルダへ移動

## セットアップ

### 1. 必要ライブラリのインストール

```bash
cd video-organizer
pip install -r requirements.txt
```

### 2. Google Drive API の認証情報を取得

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセス
2. プロジェクトを作成（または既存プロジェクトを選択）
3. 「APIとサービス」→「ライブラリ」から **Google Drive API** を有効化
4. 「APIとサービス」→「認証情報」→「認証情報を作成」→「OAuthクライアントID」を選択
5. アプリケーションの種類は「デスクトップアプリ」を選択
6. 作成後、JSONファイルをダウンロード
7. ダウンロードしたファイルを `credentials.json` にリネームし、`video-organizer/` ディレクトリに配置

> **注意:** OAuth同意画面の設定も必要です。「APIとサービス」→「OAuth同意画面」から設定してください。テスト段階では「外部」を選択し、テストユーザーに自分のGoogleアカウントを追加してください。

### 3. Gemini API キーの設定

1. [Google AI Studio](https://aistudio.google.com/apikey) にアクセス
2. 「Create API Key」でAPIキーを発行
3. `.env` ファイルを編集し、APIキーを設定：

```
GEMINI_API_KEY=あなたのAPIキー
```

### 4. 初回認証

初回実行時、ブラウザが自動で開き、Googleアカウントの認証画面が表示されます。

1. 自分のGoogleアカウントでログイン
2. Google Driveへのアクセスを許可
3. 認証が完了すると `token.json` が自動生成されます（次回以降は自動認証）

### 5. 実行

```bash
python organize.py
```

確認メッセージが表示されるので、`y` を入力して処理を開始します。

## フォルダ構成（整理後）

```
撮影素材/
├── 縦動画/
│   ├── 4月/
│   │   ├── 1日〜5日/
│   │   ├── 6日〜10日/
│   │   └── ...
│   └── 5月/
│       └── ...
└── 横動画/
    ├── 4月/
    │   ├── 11日〜15日/
    │   └── ...
    └── ...
```

## ファイル構成

| ファイル | 説明 |
|---|---|
| `organize.py` | メインスクリプト |
| `.env` | Gemini APIキー |
| `credentials.json` | Google OAuth2.0 認証情報 |
| `token.json` | 認証トークン（自動生成） |
| `requirements.txt` | 必要ライブラリ一覧 |
