# 書籍購入特典キャンペーン LP

書籍購入特典キャンペーンのモックアップランディングページです。モダンで親しみやすいデザインで、レスポンシブ対応しています。

## 📋 概要

このLPは、書籍購入者向けの限定特典キャンペーンを告知するためのページです。特典内容の紹介から申請方法まで、わかりやすく丁寧に案内します。

## ✨ 主な機能

### デザイン
- **モダンでプロフェッショナル**: 青とオレンジを基調とした洗練されたデザイン
- **レスポンシブ対応**: PC、タブレット、スマートフォンすべてに最適化
- **モバイルファースト設計**: スマートフォンでの閲覧を最優先

### アニメーション
- **スクロール時のフェードイン**: ページをスクロールすると要素が滑らかに表示
- **ホバーエフェクト**: カードやボタンにインタラクティブな動き
- **アコーディオンFAQ**: よくある質問を開閉できる機能

### 主要セクション
1. **ヘッダー**: キャンペーンタイトルとキャッチコピー
2. **特典内容**: 3つの特典をカード形式で紹介
3. **申請方法**: 3ステップでわかりやすく説明
4. **対象書店**: 購入可能な書店リスト
5. **注意事項**: 重要な情報をリスト形式で
6. **FAQ**: よくある質問（アコーディオン式）
7. **CTA**: 最終的な行動喚起

## 📝 カスタマイズ方法

### 色の変更
`style.css` の `:root` セクションで色を変更できます：

```css
:root {
    --primary-color: #2c5aa0;    /* メインカラー */
    --accent-color: #f39800;     /* アクセントカラー */
    /* その他の色 */
}
```

### コンテンツの変更
`index.html` で各セクションのテキストを編集できます。

### アニメーション速度の調整
`style.css` の `.fade-in` クラスで調整：

```css
.fade-in {
    transition: opacity 0.8s ease, transform 0.8s ease;
    /* 0.8s を変更することで速度調整 */
}
```
